# Дуэль шариков — ранбук

## Запуск

```bash
cd ~/projects/fast-game
.venv/bin/python main.py
```

Если установлен uv: `uv run main.py`.

Игра открывается на весь экран. F11 переключает окно / полный экран, Esc в меню — выход.

## Первая установка (на новой машине)

Нужен только если папки `.venv` нет.

```bash
cd ~/projects/fast-game
python3 -m venv .venv
.venv/bin/pip install pygame pytest pyflakes
```

pytest и pyflakes нужны только для проверок (см. ниже), для игры хватает pygame.

## Меню

| Пункт | Что это |
|---|---|
| 1. Два игрока | синий слева против красного справа |
| 2–4. Против компьютера | вы — синий слева, компьютер — справа; легко / средне / сложно |
| 5. Тестовый режим | два игрока по 1000 жизней — чтобы спокойно пробовать артефакты |
| 6. Артефакты | справка: значок и описание каждого артефакта |

Выбор: W/S, ↑/↓ или крестовина. Начать: Enter, Пробел, ✕ на геймпаде или цифра 1–6.
Из справки назад: Esc, Enter, Пробел, ✕ или ○.

Если жизней больше 5, в панели рисуется 5 сердечек и «+остаток»: например, `♥♥♥♥♥ +5` — это 10 жизней.

## Управление

| | Синий (слева) | Красный (справа) | Геймпад |
|---|---|---|---|
| Движение | W / S | ↑ / ↓ | левый стик или крестовина |
| Выстрел | Пробел | Enter | R1 или R2 |
| Артефакты, ячейки 1–4 | 1 2 3 4 | 9 0 - = | □ △ ○ ✕ |
| В меню | Esc | Esc | Options |
| После победы: ещё раз | R | R | ✕ |

Клавиши работают в любой раскладке. Клавиатура и геймпады работают одновременно.

## Геймпады

Оба геймпада подключаются по USB-проводу, ничего настраивать не нужно.

- **Первый подключённый — синий (слева), второй — красный (справа).** Чтобы поменять, переподключите их в нужном порядке.
- В режиме против компьютера играет первый геймпад.
- Внизу меню написано, какие геймпады найдены и кто за кого играет.
- У игрока с геймпадом ячейки инвентаря стоят ромбом, как кнопки: △ сверху, □ слева, ○ справа, ✕ снизу. С клавиатуры — в ряд 1–4.

Можно и по Bluetooth: беспроводной PS4-геймпад уже сопряжён, достаточно нажать на нём кнопку **PS**.

### Если геймпад не работает

1. Проверить, видит ли его система:
   ```bash
   ls /dev/input/js*
   ```
   На каждый геймпад должно быть устройство `js0`, `js1`.
2. Не видит → переподключить кабель, попробовать другой USB-порт.
3. Bluetooth не подключается → зажать **Share + PS** (на DualSense: **Create + PS**), пока подсветка не замигает часто, затем в «Настройки → Bluetooth» удалить «Wireless Controller» и выбрать его заново.
4. Геймпад подключили, когда игра уже запущена — игра подхватит его сама. Если нет, перезапустить игру.

## Патроны

- В начале партии у каждого 50 патронов, верхнего лимита нет.
- Каждый выстрел тратит 1 патрон, веер из трёх пуль — тоже 1. Двойники стреляют бесплатно.
- Пачки по 20 патронов появляются на вертикали игрока в среднем раз в 10 с (≈120 патронов в минуту) и лежат 10 с.
- Пачка подбирается сразу, в инвентарь не идёт — подбирается даже при полном инвентаре.
- Патроны кончились — счётчик в панели красный, при попытке выстрела всплывает «нет патронов».

## Артефакты

Полное описание с значками — в игре, пункт меню «Артефакты».

- Появляются на вертикали игрока, пока в его инвентаре (4 ячейки) есть место. Подобрал — артефакт лёг в ячейку, нажал кнопку ячейки — сработал.
- Лечение срабатывает сразу при подборе, даже если инвентарь полон.
- Рамка: зелёная — защита, синяя — атака, оранжевая — бьёт по сопернику.
- Дебаффы соперника снимаются только временем или очищением — больше ничем.
- Стен можно поставить несколько, каждая стоит своё время.
- Эффекты складываются: разные действуют одновременно (заморозка + «не стреляет», волна + веер + скорость), повтор того же эффекта добавляет ему время.
- На двойников переходят эффекты хозяина: щит, волна, веер, скорострельность, ×2, уменьшение, сбивание пуль, скорость, «не стреляет».

| Группа | Артефакт | Что делает |
|---|---|---|
| Защита | щит | гасит 5 пуль или держится 7 с — что раньше; над шариком видно удары и секунды |
| | лечение | +3 жизни сразу при подборе |
| | очищение | снимает с тебя и двойников все дебаффы; работает даже под запретом артефактов |
| | уменьшение | ты меньше в 2 раза, 7 с |
| | скорость | движение ×1,8, 7 с |
| | убрать пули соперника | все пули соперника исчезают с экрана |
| | пули соперника медленнее | примерно вдвое, 7 с |
| Атака | веер | 5 выстрелов сразу в три стороны |
| | скорострельность | пауза между выстрелами 0,1 с, 7 с |
| | пули волной | твои пули летят синусоидой, 7 с |
| | двойники | два шарика сами ходят и стреляют, умирают с одного попадания |
| | сбиваешь пули | твои пули уничтожают встречные пули соперника, 8 с |
| | стена-зеркало | пули соперника отражаются и становятся твоими, твои поглощаются, 8 с |
| Дебаффы | соперник ×2 | соперник больше в 2 раза, 7 с |
| | заморозить соперника | не может двигаться 2,5 с, стрелять может |
| | соперник не стреляет | 4 с |
| | соперник: управление наоборот | вверх и вниз меняются местами, 5 с |
| | соперник без артефактов | не может использовать артефакты (кроме очищения), 5 с; подбирать может |

## Настройки

Все числа и цвета — в `duel/config.py`:

- громкость — `MUSIC_VOLUME`, `SHOOT_VOLUME`;
- жизни — `MAX_HP`, в тестовом режиме — `TEST_HP`, лечение — `HEAL_AMOUNT`;
- щит — `SHIELD_HITS` и `DURATION["shield"]`;
- патроны — `START_AMMO`, `AMMO_PACK`, `AMMO_SPAWN`, `AMMO_LIFETIME`;
- длительность эффектов — словарь `DURATION`;
- частота артефактов — `ARTIFACT_SPAWN`, `ARTIFACT_LIFETIME`.

Ещё два места:

- сила компьютера — словарь `AI_LEVELS` в `duel/ai.py`;
- мёртвая зона стика — `PAD_DEAD` в `duel/gamepad.py`.

## Музыка и звуки

Музыка лежит в `assets/music/`, звуки — в `assets/sounds/`. Музыка подбирается по имени, так что новый трек достаточно положить в папку с подходящим именем:

| Файлы | Когда играет |
|---|---|
| `assets/music/menu-*.mp3` | меню и справка, по кругу |
| `assets/music/background-*.mp3` | игра: все треки по очереди, вперемешку; кончился один — начинается другой |
| `assets/sounds/shoot01.mp3` / `shoot02.mp3` | выстрел синего / красного |

Громкость — `MUSIC_VOLUME`, `SHOOT_VOLUME`.

## Структура проекта

```
main.py              запуск
assets/music/        музыка
assets/sounds/       звуки
assets/sprites/      пиксельные спрайты (PNG)
tools/make_sprites.py  рисует спрайты в assets/sprites/
duel/                игра
  config.py          все настройки: размеры, скорости, длительности, патроны, цвета, звук
  items.py           артефакты: таблица, справка, группы, цвета рамок
  icons.py           значки артефактов
  entities.py        игрок, двойник, пуля, стена, артефакт, пачка патронов
  ai.py              компьютерный соперник и уровни сложности
  gamepad.py         геймпады
  audio.py           музыка и звуки
  screens.py         отрисовка: поле, верхняя панель, меню, справка
  sprites.py         загрузка и масштаб спрайтов
  game.py            цикл игры, ввод, правила, применение артефактов
tests/               автотесты
```

Новый артефакт: строка в `ITEMS` и `HELP_SECTIONS` и описание в `item_help` (`duel/items.py`), значок в `duel/icons.py`, действие в `Game.apply_item` (`duel/game.py`).

## Проверки

Перед коммитом:

```bash
cd ~/projects/fast-game
.venv/bin/python -m pyflakes main.py duel tests   # опечатки и забытые импорты
.venv/bin/python -m pytest -q                     # автотесты, ~2 секунды
```

Тесты запускают игру без окна и без звука: артефакты, эффекты, щит, стены, двойники, патроны, управление с клавиатуры и геймпада, меню, партии с компьютером, отрисовку всех экранов.

## Спрайты

Игроки — маги с автоматами, пиксель-арт 32×32: `assets/sprites/mage_blue.png` и `mage_red.png`. Это один рисунок в цветах команды; красный в игре отзеркален и смотрит влево.

- Перерисовать из кода: `.venv/bin/python tools/make_sprites.py` (рисунок и цвета команд — в самом скрипте).
- Можно править PNG в любом пиксель-редакторе (Pixelorama, LibreSprite, Aseprite) — размер 32×32, прозрачный фон, маг смотрит вправо.
- Попадания считаются по кругу, спрайт рисуется в нём по центру и масштабируется вместе с ним (×2, уменьшение). Насколько спрайт больше круга — `SPRITE_TO_HITBOX` в `duel/sprites.py`.
