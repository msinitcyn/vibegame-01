# Сервер Spellgunners на AWS (Lightsail) — пошагово

Что получится: игровой сервер в интернете 24/7 по адресу `wss://имя.duckdns.org/` — к нему подключаются
и компьютерная игра, и браузерная версия. Шифрование (сертификат) — бесплатное, получается само.

Цена: **Lightsail $5 в месяц** (≈5 €): 2 vCPU, 512 МБ памяти, 20 ГБ диска, 1 ТБ трафика, постоянный IPv4.
Игре это с запасом (сжатый трафик — ~14 МБ в час на игрока). Цены сверить: https://aws.amazon.com/lightsail/pricing/

Время: ~1 час в первый раз. Названия кнопок в консоли AWS иногда меняются — ищите по смыслу.

---

## 1. Есть ли у вас аккаунт AWS

1. Откройте https://console.aws.amazon.com/ → **Sign in** → **Root user** → введите почту, на которую
   мог быть заведён аккаунт.
2. Если просит пароль — аккаунт есть. Пароль не помните — **Forgot password**: письмо придёт, только
   если аккаунт на эту почту существует. Проверьте и другие свои почты.
3. Если аккаунт нашёлся и вы в нём: сверху справа имя → **Account** — проверьте, что он активен;
   **Billing and Cost Management** → **Bills** — нет ли там чего-то забытого и платного.
4. Аккаунта нет — шаг 2.

## 2. Создать аккаунт (если его нет)

1. https://aws.amazon.com/ → **Create an AWS Account**.
2. Почта, имя аккаунта (например, `spellgunners`), пароль — сохраните в менеджер паролей.
3. Тип плана: AWS предлагает **Free plan** и **Paid plan**. Берите **Paid plan**: бесплатный через
   несколько месяцев закрывает аккаунт вместе с сервером, а стартовые кредиты (до $200) дают и платному.
4. Карта (спишут и вернут ~1 $ для проверки), телефон (код в SMS или звонком), план поддержки —
   **Basic (free)**.
5. Дождитесь письма «аккаунт активирован» (обычно минуты, иногда до суток).

## 3. Защитить аккаунт и поставить потолок расходов (обязательно)

1. **Двухфакторный вход**: справа сверху имя → **Security credentials** → **Multi-factor authentication
   (MFA)** → **Assign MFA device** → приложение-аутентификатор на телефоне (Google Authenticator, Aegis…).
2. **Письмо о расходах**: найдите в поиске консоли **Budgets** → **Create budget** → шаблон
   **Monthly cost budget** → сумма **10 USD** → свою почту → **Create**. Если вдруг расходы пойдут к 10 $ —
   придёт письмо.

## 4. Создать сервер в Lightsail

1. Откройте https://lightsail.aws.amazon.com/ → **Create instance**.
2. **Region** — ближайший к игрокам: для Финляндии — **Stockholm (eu-north-1)**, для Европы в целом —
   **Frankfurt (eu-central-1)**.
3. **Platform: Linux/Unix**, **Blueprint: OS Only → Ubuntu 24.04 LTS**.
4. **SSH key**: оставьте ключ по умолчанию (входить будем прямо из браузера, кнопкой в консоли).
5. **Plan**: вкладка **Dual-stack** → **$5 USD** (512 MB, 2 vCPUs, 20 GB, 1 TB). Не берите **IPv6-only**:
   у многих провайдеров IPv6 нет, игроки не подключатся.
6. Имя: `spellgunners` → **Create instance**. Через минуту статус станет **Running**.

## 5. Постоянный адрес и файрвол

1. Lightsail → вкладка **Networking** → **Create static IP** → выберите свой сервер → имя
   `spellgunners-ip` → **Create**. Запишите адрес (например, `13.48.10.20`). Пока IP привязан к серверу —
   он бесплатный (непривязанный — платный, поэтому удаляйте его вместе с сервером).
2. Откройте сервер → вкладка **Networking** → **Firewall** (одна таблица для IPv4 и IPv6; в старой
   консоли — две: IPv4 и IPv6, правила те же). Должно быть три правила:

   | Application | Port | Allowed inbound traffic |
   |---|---|---|
   | SSH | 22 | **Lightsail browser SSH** (без «Any» — тогда из интернета SSH закрыт; входите кнопкой в консоли) |
   | HTTP | 80 | Any IPv4 or IPv6 address (получение сертификата) |
   | HTTPS | 443 | Any IPv4 or IPv6 address (сама игра, `wss://`) |

   На «This rule allows any IP address…» у 80 и 443 — так и нужно: игроки приходят откуда угодно.
   Остальные правила удалите.

## 6. Имя сервера (бесплатно, DuckDNS)

1. https://www.duckdns.org/ → войдите через GitHub или Google.
2. В поле **sub domain** — имя, например `spellgunners` → **add domain**.
3. В строке этого имени в поле **current ip** — постоянный адрес из шага 5 → **update ip**. Внимание:
   DuckDNS сам подставляет адрес вашего домашнего компьютера — замените его на адрес из Lightsail.
4. Проверка у себя в терминале: `getent hosts spellgunners.duckdns.org` — должен показать этот адрес
   (иногда через пару минут).

## 7. Поставить игру на сервер

1. Lightsail → ваш сервер → **Connect using SSH** (оранжевая кнопка) — откроется терминал в браузере.
   При создании Lightsail пишет «Security update recommended» (и «PHP update» — к OS Only не относится:
   PHP там нет, проверка `php -v` → `command not found`). Обновления ставит сам `install.sh`; если в конце
   он скажет перезагрузиться — `sudo reboot`, сервер игры поднимется сам.
2. Вставьте по очереди (вместо `spellgunners.duckdns.org` — своё имя из шага 6):

   ```bash
   sudo apt-get update && sudo apt-get install -y git
   sudo git clone https://github.com/msinitcyn/vibegame-01 /opt/spellgunners
   cd /opt/spellgunners && sudo bash deploy/install.sh spellgunners.duckdns.org
   ```

   Скрипт ставит последний выпуск игры, сайт (страница и браузерная версия), Caddy (сертификат и `wss://`), службу игрового сервера, файрвол
   (SSH, 80, 443), автообновления безопасности Ubuntu, ежедневную копию базы аккаунтов и автообновление
   сервера на новые выпуски. Сам сервер работает от
   отдельного пользователя без прав и слушает только эту машину — наружу его видно только через Caddy.
3. Проверка на сервере:

   ```bash
   curl -s http://127.0.0.1:5557/health        # ok
   curl -s http://127.0.0.1:5557/              # сводка: версия, комнаты, игроки, ошибки
   sudo journalctl -u caddy --since "10 min ago" | grep -i certificate   # сертификат получен
   ```

## 8. Сыграть

- **Компьютерная игра**: «Играть по сети» → строка адреса → `wss://spellgunners.duckdns.org/` → Enter.
  (Нужна версия игры, которая понимает `wss://`, — с ближайшего выпуска.)
- **Браузерная версия и сайт**: https://spellgunners.duckdns.org/ — страница сервера: «Play in the browser»,
  скачать игру, сколько сейчас онлайн. Браузерная версия лежит на самом сервере (`/play/`) и обновляется
  вместе с ним; если в выпуске её нет — кнопки «играть в браузере» на странице нет.

## 9. Обслуживание

| Что | Команда (в терминале сервера) |
|---|---|
| Обновить на последний выпуск сейчас (обычно не нужно — см. ниже) | `sudo bash /opt/spellgunners/deploy/update.sh` |
| Что делало автообновление | `sudo journalctl -t spellgunners-update --since today` |
| Состояние службы | `systemctl status spellgunners` |
| Лог сервера (последние строки) | `sudo tail -n 50 /var/lib/spellgunners/logs/server.log` |
| Ошибки | `sudo grep ERROR /var/lib/spellgunners/logs/server.log` |
| Аккаунты | `cd /opt/spellgunners && sudo -u spellgunners python3 -m duel.server users list --db /var/lib/spellgunners/server.db` |
| Заблокировать аккаунт | `... users ban Имя --db /var/lib/spellgunners/server.db` (как строкой выше) |
| Копии базы | `ls /var/lib/spellgunners/backups/` (последние 14 дней) |
| Перезапустить | `sudo systemctl restart spellgunners` |
| Переложить сайт (страница и браузерная версия) | `sudo bash /opt/spellgunners/deploy/site.sh` |
| Применить новый Caddyfile после обновления (если менялся `deploy/Caddyfile.template`) | `cd /opt/spellgunners && sudo bash deploy/install.sh spellgunners.duckdns.org` |

**Обновления сервера — сами.** Сервер стоит на выпуске (теге `vX.Y.Z`), как и игры у игроков. Раз в
10 минут он проверяет GitHub: вышел новый выпуск — ставит его и перезапускается, но только когда на сервере
никто не играет (если сидят дольше 6 часов — всё равно). Так сервер не отстаёт от игр: выпустили версию —
через несколько минут она и на сервере.

Отчёты о падениях от игроков — `/var/lib/spellgunners/logs/client-crashes/`, повторы партий —
`/var/lib/spellgunners/logs/replays/` (скачать к себе: `scp` или кнопка в консоли Lightsail).

## 10. Выпуски, которым нужен шаг на сервере

Автообновление переключает **код** и перезапускает игровой сервер, но **не трогает системные настройки**:
Caddy (`/etc/caddy/Caddyfile`), службы и таймеры systemd. Их ставит только `install.sh`. Поэтому если в
выпуске менялись файлы `deploy/` (кроме `autoupdate.sh` и `site.sh` — эти работают сразу), после выпуска
на сервере нужно один раз:

```bash
cd /opt/spellgunners && sudo bash deploy/install.sh spellgunners.duckdns.org
```

Повторный запуск безопасен: обновит Ubuntu, поставит последний выпуск игры, разложит сайт, применит
настройки Caddy и служб. Игровой сервер при этом перезапустится — лучше, когда никто не играет.

| Выпуск | Что изменилось на сервере | Что сделать |
|---|---|---|
| 0.8.2 | первая установка | шаг 7 |
| 0.8.3 | сайт сервера (страница, браузерная версия в `/play/`, `/status.json`) — новые правила Caddy | `install.sh` (команда выше), затем `sudo bash /opt/spellgunners/deploy/site.sh` и `sudo systemctl restart spellgunners` (`install.sh` из 0.8.2 не знал шага сайта и не перезапускал сервер; с 0.8.4 — сам) |

Проверка после `install.sh`:

```bash
curl -s http://127.0.0.1:5557/health                        # ok — игровой сервер жив
curl -s https://spellgunners.duckdns.org/status.json        # {"version": "0.8.3", "ok": true, …}
ls /var/www/spellgunners/play/                               # index.html, web-src.apk — браузерная версия
sudo journalctl -u caddy --since "10 min ago" | tail -n 5   # без ошибок
```

## 11. Выключить и не платить

Lightsail → сервер → **⋮ → Delete**; затем **Networking** → статический IP → **Delete**. Остановленный
(stopped) сервер всё равно оплачивается — только удаление.

## Что защищает сервер

- Наружу открыты только 22 (SSH), 80 (получение сертификата), 443 (игра через `wss://`); TCP-порт 5555
  наружу закрыт — пароли аккаунтов идут только по шифрованному соединению.
- Сервер работает от пользователя `spellgunners` без прав, в песочнице systemd (пишет только в
  `/var/lib/spellgunners`).
- Лимиты: не больше 6 соединений с одного адреса, 150 сообщений в секунду от соединения, 10 неудачных
  входов за 5 минут и 3 новых аккаунта в час с адреса, ограничение размеров сообщений, отчётов о падениях.
  Настоящий адрес игрока сервер берёт у Caddy (только у прокси на этой же машине).
- Ubuntu сама ставит обновления безопасности; база аккаунтов копируется каждый день.
