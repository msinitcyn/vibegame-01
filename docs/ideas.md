## Промо-ролик вместо обучения (24.11.2026)

Обучение — в стиле промо-ролика: коротко, громко, под музыку (музыку подберёт автор). Лор («давным-давно…») — может быть, потом, отдельно.

Сцены (крупная надпись + маленькая настоящая партия под ней):

1. **«Спеллганнерс!»** — появляются и пропадают разные маги (все герои по очереди).
2. **«Стреляй!»** — маги стреляют друг в друга.
3. **«Руби!»** — месятся мечами (ближний бой).
4. **«Выбивай артефакты!»** — бьют мобов, из них выпадают артефакты, маги их подбирают.
5. **«Колдуй!»** — эффектные заклинания героев одно за другим.
6. **«Помни: чужая земля жжёт!»** — маг забегает на чужую землю, горит, убегает.

Как работает:
- запускается при первом старте игры, один раз (флаг в настройках);
- Esc прерывает;
- пересмотреть можно в меню: пункт «Артефакты: что делает каждый» переименовать в «Обучение»
  и добавить в него вкладку «Об игре» с роликом.

## Сначала — движок роликов (24.11.2026)

Чтобы делать полноценные ролики (этот и следующие), сначала улучшить движок сценок (`duel/demos.py`).
Сейчас сценка — одна партия двух магов в окошке справки, по кругу. Для роликов нужно:

- **последовательность сцен** с переходами (затемнение, вспышка), а не одна сценка по кругу;
- **надписи поверх — как субтитры**: отдельный файл на каждый язык с отметками времени (с какой по какую
  секунду ролика показывать какую строку), например `assets/movies/<ролик>/subs.ru.json`, `subs.en.json`
  (или формат вроде SRT). Языков в перспективе может стать больше — новый язык = новый файл субтитров,
  сценарий ролика не трогаем; нет файла для языка — берём английский. Вид надписи (крупная, с анимацией
  появления) — в сценарии, сам текст — только в субтитрах;
- **камера**: показать весь экран или участок поля, плавный наезд и сдвиг за магом;
- **маги появляются и исчезают** по сценарию (вспышка, смена героя), больше двух магов на сцене —
  например, чтобы представить всех героев («интродьюсить магов»: имя, цвет, коронный артефакт);
- **мобы и артефакты по сценарию**: выпадение и подбор, злые и спокойные;
- **музыка ролика** (свой трек) и звуки сцен;
- **пропуск** (Esc) и «смотреть ещё раз»;
- сценарий — текстовый файл (как `assets/demos/*.json`), F5 перечитывает.

Потом на этом движке: промо-ролик, представление героев, может быть, лор.
