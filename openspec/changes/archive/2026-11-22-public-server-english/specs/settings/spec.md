## MODIFIED Requirements

### Requirement: Настройки сохраняются
Выбранный язык, имя игрока и адрес последнего сервера, к которому удалось подключиться, SHALL сохраняться в файле настроек пользователя и применяться при следующем запуске; повреждённый или отсутствующий файл MUST приводить к настройкам по умолчанию (английский, без имени, адрес `localhost`) без ошибки.

#### Scenario: Перезапуск
- **WHEN** игрок выбрал suomi и перезапустил игру
- **THEN** игра открывается на финском

#### Scenario: Битый файл
- **WHEN** файл настроек повреждён
- **THEN** игра запускается на русском

#### Scenario: Последний адрес
- **WHEN** игрок подключился к `192.168.1.5`, вышел из игры и снова открыл «Подключиться»
- **THEN** в поле адреса уже стоит `192.168.1.5`
