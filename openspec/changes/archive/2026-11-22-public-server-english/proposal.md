## Why

Сервер в интернете поднят (`wss://spellgunners.duckdns.org/`, проверено: отвечает 0.8.2, сжатие работает). Игроки должны попадать на него без набора адреса — и с компьютера, и из браузера. Игра выходит за пределы семьи — язык по умолчанию английский.

## What Changes

- `config.PUBLIC_SERVER` — сервер в интернете. На экране серверов он первой строкой («Сервер «Spellgunners» — в интернете») и выбран сам: «Играть по сети» → Enter. Если игрок запустил свой сервер, выбран свой. Найденные в локальной сети, ручной ввод и «Создать свой сервер» — ниже, как раньше. В браузере — сервер в интернете и адрес вручную (по умолчанию — тот же сервер).
- Язык по умолчанию (первый запуск, битые настройки) — английский. Сохранённый выбор не меняется; запасной язык для непереведённых строк — по-прежнему русский.

## Capabilities

### Modified Capabilities
- `network-play`: свой сервер — первым, если запущен; иначе сервер в интернете.
- `settings`: английский по умолчанию.

## Impact

- `duel/config.py`, `duel/client_lobby.py`, `duel/screens_net.py`, `duel/settings.py`, `main.py`, `duel/i18n.py`; тесты.
