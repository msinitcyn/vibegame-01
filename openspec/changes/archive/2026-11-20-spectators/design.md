# Design

## Decisions

1. **Роль в join**: `{"type": "join", "role": "spectator"}` → `{"type": "watch"}`; зрителей больше `MAX_SPECTATORS` → `full`. Роль `player` без свободного места → `full`, как раньше.
2. **Клиент**: `connect(role="player")` получил `full` → сразу `connect(role="spectator")`. Зритель — `Game.me is None` при `Game.net`; команды не шлёт, клавиши игры и лобби (кроме Esc) не действуют.
3. **Сервер**: `self.spectators` — список соединений; снимок `state` уходит и им; поле `spectators` — их число. Такт сервера идёт, если есть хоть кто-то (игроки, зрители, отошедшие). Закрытые соединения зрителей убираются; сообщения зрителей, кроме `leave`, игнорируются; тишина зрителя не считается обрывом (он ничего не шлёт).
4. **Обрыв у зрителя** — переподключение тем же способом, но с ролью `spectator`.
