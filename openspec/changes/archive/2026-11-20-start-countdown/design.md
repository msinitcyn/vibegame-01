# Design

## Решения

1. **Число** — `config.COUNTDOWN = 3.0`; код читает его во время работы (`config.COUNTDOWN`), чтобы тесты могли поставить 0 (им отсчёт не нужен) и проверять сам отсчёт отдельно.
2. **Сервер** — фаза `countdown` между `lobby`/`over` и `play`: матч не шагает, отсчёт уменьшается на такт (на паузе — стоит). В `state` — поле `countdown` (секунд осталось, 0 — нет).
3. **Хотсит и разминка** — `Game.countdown`: пока он больше 0, в главном цикле матч не шагает, нажатия сбрасываются. Ставится в `start()`, на «ещё раз» (R) и в начале разминки.
4. **Экран** — крупная цифра (3, 2, 1) по центру поля; полсекунды после конца — «В бой!».
