## ADDED Requirements

### Requirement: Сайт сервера
По адресу сервера в браузере SHALL открываться страница: играть в браузере (версия того же выпуска, что сервер), скачать игру для Windows и Linux, состояние сервера (работает ли, сколько игроков и партий, версия). Публично MUST показываться только эти сведения — без ошибок и внутренних подробностей. Игра по `wss://` на тот же адрес MUST работать как раньше.

#### Scenario: Открыть адрес сервера
- **WHEN** человек открыл https://spellgunners.duckdns.org/
- **THEN** видит кнопку «Play in the browser», ссылки для Windows и Linux и «Server is up · players: N»
