# Design

## Decisions

1. **`Conn.recv`** — каждая строка разбирается отдельно; `ValueError`/не `dict` → `conn.violation = причина`, соединение закрыто; накопленный хвост без `\n` больше `MAX_LINE` (64 КБ) → то же. Уже разобранные хорошие сообщения из того же чтения отдаются.
2. **Проверка команд** — функция `parse_move(value)`: список/кортеж из двух чисел (не bool), каждое приводится к -1/0/1; иначе `None` (команда без движения). `slot` — только 0..3, `aim` — конечное число (уже было).
3. **Лимиты** — `MAX_PENDING = 16` новичков, `MAX_CONNS = 32` всего (игроки + зрители + новички); при `accept` сверх лимита — закрыть сразу.
4. **Изоляция** — обработка каждого соединения в `read()` и `seat_newcomers()` под `try/except Exception`: закрыть это соединение (у игрока — как обрыв связи), записать в журнал. В цикле `run()` ошибка такта — в журнал с трассировкой, цикл продолжается.
