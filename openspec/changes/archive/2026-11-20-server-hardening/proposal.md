# Proposal

## Why

Сервер должен работать круглосуточно на домашнем устройстве «как настоящий», а потом — в интернете. Проверка показала: одна кривая строка от любого подключения (не JSON, список вместо объекта, `move` строкой или из трёх чисел) роняет сервер целиком; строку без перевода он копит без предела (25 МБ и дальше); число подключений не ограничено.

## What Changes

- Кривое сообщение (не JSON, не объект, слишком длинное — больше 64 КБ) — нарушение протокола: соединение закрывается, сервер работает дальше, в журнале — запись.
- Значения команд проверяются: `move` — два числа из -1/0/1, иначе команда пропускается; прочие поля — только нужного типа.
- Лимит подключений: не больше 16 ждущих приветствия и 32 соединений всего; лишние закрываются сразу.
- Последний рубеж: ошибка при обработке одного соединения закрывает только его; ошибка такта сервера пишется в журнал, сервер продолжает.
- Клиент так же переживает кривые сообщения сервера (обрыв связи вместо падения игры).
