## ADDED Requirements

### Requirement: Защита сервера
Сервер SHALL продолжать работу при любых данных от любого подключения. Сообщение, которое не является объектом JSON или длиннее 64 КБ, MUST закрывать только это соединение (у игрока — как обрыв связи). Неверные значения в команде (например, движение не из двух чисел) MUST NOT менять партию и MUST NOT ронять сервер. Сервер MUST держать не больше 16 подключений, ещё не приславших приветствие, и не больше 32 соединений всего; лишние закрываются сразу.

#### Scenario: Кривая строка
- **WHEN** во время партии одно из подключений присылает строку «hello» вместо JSON
- **THEN** это соединение закрывается, а сервер и партия у остальных продолжаются

#### Scenario: Бесконечная строка
- **WHEN** подключение шлёт данные без перевода строки больше 64 КБ
- **THEN** сервер закрывает это соединение и не копит данные дальше

#### Scenario: Наплыв подключений
- **WHEN** открыто 40 подключений, ничего не присылающих
- **THEN** сервер держит не больше 16 из них, остальные закрыты, а игроки играют как обычно
