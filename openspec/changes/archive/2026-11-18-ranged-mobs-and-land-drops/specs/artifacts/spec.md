# Spec Delta

## ADDED Requirements

### Requirement: Артефакт лежит до подбора
Выпавший артефакт SHALL лежать на месте гибели моба, пока маг сам не подберёт его касанием; по времени он MUST NOT исчезать и MUST NOT подбираться автоматически.

#### Scenario: Маг не подошёл
- **WHEN** артефакт выпал, а маг минуту к нему не подходит
- **THEN** артефакт всё ещё лежит на том же месте

#### Scenario: Маг подошёл
- **WHEN** маг касается артефакта
- **THEN** артефакт подбирается

## MODIFIED Requirements

### Requirement: Артефакты выпадают только из мобов
Артефакты SHALL появляться на поле только при убийстве моба: случайный артефакт из всех видов падает ровно в месте гибели моба — и только если это место на земле того мага, чья пуля добила моба. На полосе мобов и на земле соперника артефакт MUST NOT выпадать. Сами по себе по таймеру артефакты MUST NOT появляться.

#### Scenario: Убит моб
- **WHEN** пуля красного добивает моба, который зашёл на лаву
- **THEN** на месте гибели моба появляется артефакт

#### Scenario: Убит моб на нейтральной полосе
- **WHEN** пуля красного добивает моба в полосе мобов
- **THEN** артефакт не появляется

#### Scenario: Без мобов
- **WHEN** в течение минуты ни один моб не убит
- **THEN** на поле нет ни одного артефакта

## REMOVED Requirements

### Requirement: Артефакт лежит ограниченное время
**Reason**: Артефакт теперь выпадает только на земле добившего, и забрать его может только он — исчезновение по таймеру больше не нужно; игрок сам решает, когда идти за наградой.
**Migration**: Заменено требованием «Артефакт лежит до подбора».
