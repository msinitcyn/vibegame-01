# Design

## Решения

1. `Finder(port, targets=None, known=())` — к каждому вопросу «всем» добавляется вопрос напрямую каждому адресу из `known` (на порт поиска 5556). В `known` — только адреса-числа (IPv4): имена вроде `pc.local` пришлось бы разрешать через DNS, а это может подвесить кадр.
2. Настройка `recent_servers` — до 5 последних адресов, к которым удалось подключиться (новые — в начало); `last_address` остаётся для строки ручного ввода.
3. `ASK_EVERY = 0.5`, `FRESH = 10`.
