# Proposal

## Why

Дома должен постоянно работать сервер «как настоящий», чтобы потом его можно было просто перенести в интернет. Сейчас один сервер — одна партия на двоих: вторая пара играть на нём не может, а «сервер» живёт только пока открыта игра создателя.

## What Changes

- **Сервер с лобби и комнатами** на одном порту: в каждой комнате — своя партия (места, «готов», реванш, переподключение, зрители — как раньше). Комнаты создаются игроками и исчезают, когда в них никого нет. До 16 комнат.
- **Меню**: вместо «Создать игру по сети» и «Подключиться» — один пункт **«Играть по сети»**:
  - экран **серверов**: найденные в сети (имя, комнат, игроков), свой сервер, ручной ввод адреса, строка **«Создать свой сервер»**;
  - «Создать свой сервер» поднимает сервер внутри игры и сразу подключает к нему; он работает, пока открыта игра (или до «Остановить»);
  - экран **комнат** сервера: «Создать комнату», комнаты (кто сидит, идёт ли партия, зрители): Enter — войти (мест нет — смотреть), Y/△ — смотреть;
  - Esc из комнаты — назад к списку комнат; из списка комнат — к серверам; из серверов — в меню.
- **Бот**: в лобби комнаты любой игрок жмёт B (△) — на свободное место садится бот.
- `python -m duel.server --name "Дом"` — постоянный сервер для домашнего устройства (тот же код).
- **BREAKING (сеть)**: протокол 4 → 5.
