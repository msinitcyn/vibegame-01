## Why

Автор хочет промо-ролик вместо обучения и дальше — другие ролики (представление героев, может быть, лор). Сначала нужен движок роликов: он гоняет по экрану сцены из игры, сцены программируются через внутренний API, переходы между сценами движок добавляет сам, надписи — субтитрами по языкам (языков может стать больше). Идея — `docs/ideas.md`.

## What Changes

- Новый модуль `duel/movie.py`: ролик = последовательность сцен; сцена — маленькая настоящая партия (как сценки справки), но с камерой, появлением и исчезновением магов, сменой героя, мобами и артефактами по сценарию, тряской камеры, замедлением.
- Внутренний API сцены — класс `Stage`: методы `move`, `walk_to`, `aim`, `fire`, `melee`, `cast`, `teleport`, `appear`, `vanish`, `hero`, `mob`, `drop`, `gear`, `camera`, `follow`, `shake`, `speed`. Сценарий в `assets/movies/<ролик>/movie.json` вызывает их по времени (`{"t": 1.2, "do": "cast", "who": "blue", "item": "beam"}`); сцену можно написать и на Python.
- Переходы между сценами (движок сам): затемнение через чёрный, растворение, белая вспышка, шторка, склейка; в начале ролика — из чёрного, в конце — в чёрный.
- Кадр в пропорциях кино (16:9, чёрные полосы сверху и снизу); субтитры — внизу, белым на чёрной плашке, из `subs.<язык>.srt` (формат SRT, время — от начала ролика); нет файла языка — английский.
- Музыка ролика (`"music"` — маска файлов в `assets/music`, иначе тишина) и звуки сцен; Esc — пропустить; F5 — перечитать.
- Запуск: `main.py --movie <ролик>` (для работы над роликом). Пример — ролик `showcase` (показывает возможности движка). Промо-ролик, первый запуск и пункт меню — следующим изменением.
