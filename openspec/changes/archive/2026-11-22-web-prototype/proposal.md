## Why

Хочется браузерную версию как «заманушку»: открыл ссылку и попробовал. Основным остаётся компьютерный клиент, и решения для браузера не должны его ухудшать. Первый шаг — прототип на pygbag без сети: понять, как игра грузится и работает в браузере.

## What Changes

- Главный цикл разделён на `frame()` (один кадр) и цикл вокруг: на компьютере — `main_loop` (как было), в браузере — `run_web()` (`asyncio`, после каждого кадра отдаёт управление странице).
- `duel/platform.py`: `WEB` (браузер; `DUEL_WEB=1` — то же на компьютере для проверки), `media()` — в браузере звуки `.ogg` вместо `.mp3`. На компьютере `WEB` ложно — поведение не меняется.
- В браузере: «Играть по сети» — сообщение «пока без сети», автообновление не проверяется. Тест с ботом, два игрока, справка, настройки — работают.
- `web/main.py` — вход браузерной версии; `tools/build_web.py` — сборка `build/web-src` (код, ресурсы, звуки переводятся в `.ogg` через ffmpeg, версия вшивается) для `python -m pygbag`.
- Ошибка, найденная по дороге (и на компьютере): нет звукового файла — игра падала (`pygame.mixer.Sound` с `Path`); теперь звук просто не загружается.
