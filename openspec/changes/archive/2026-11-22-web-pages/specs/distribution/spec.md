## ADDED Requirements

### Requirement: Браузерная версия по ссылке
Каждый выпуск SHALL собирать браузерную версию и выкладывать её на GitHub Pages после зелёных проверок, чтобы в игру можно было играть по ссылке без установки, в том числе по сети с сервером в интернете.

#### Scenario: Открыть по ссылке
- **WHEN** вышел новый выпуск, и игрок открыл ссылку браузерной версии
- **THEN** через минуту загрузки он в меню этой версии игры и может подключиться к серверу в интернете
