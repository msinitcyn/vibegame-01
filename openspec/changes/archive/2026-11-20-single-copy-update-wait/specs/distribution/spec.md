## ADDED Requirements

### Requirement: Одна копия игры
Игра SHALL запускаться на компьютере в одной копии: вторая копия MUST сообщать «Spellgunners уже запущен» (на Windows — окном) и закрываться. Переменная окружения `DUEL_MULTI=1` разрешает несколько копий (для проверки сети на одном компьютере); самопроверка `--selftest` не ограничивается.

#### Scenario: Двойной щелчок по ярлыку
- **WHEN** игра открыта, и игрок ещё раз запускает её с ярлыка
- **THEN** появляется сообщение «Spellgunners уже запущен», вторая копия не открывается
