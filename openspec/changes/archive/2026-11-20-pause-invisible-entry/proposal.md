# Proposal

## Why

Игрок хотел поменять настройки посреди партии: Esc выкинул в меню, второй Esc закрыл игру. При входе на сервер (экран «Как войти?») связь рвалась через 5 секунд — создать аккаунт не получалось. Дети хотят новое заклинание Свету — невидимость.

## What Changes

- Esc в партии — пауза («Продолжить», «Настройки», «Выйти»); за одним компьютером матч стоит, по сети — идёт, маг стоит; из настроек — обратно в партию.
- Esc в главном меню больше не закрывает игру (только кнопка «Выход»).
- Клиент на экране «Как войти?» сообщает серверу «жду» — сервер не закрывает соединение.
- Новый артефакт Света «невидимость» (6 с, уровень 2).

### New Capabilities

### Modified Capabilities

- `controls`: Esc больше не закрывает игру.
- `menus`: пауза в партии.
- `network-play`: выход из сетевой партии — через паузу.
- `accounts`: экран входа не рвёт связь.
- `artifacts`: «невидимость» Свету.
