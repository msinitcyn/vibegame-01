# Design

1. **Пауза** — флаг `paused` в состоянии `play`. Локально главный цикл не шагает матч; по сети `net_frame` шлёт пустые команды. Настройки с паузы: `settings_back = "play"`, пока они открыты, `background_play` слушает сеть и лобби. Нажатия на паузе идут в меню паузы, а не в партию.
2. **«Жду»** — сообщение `{"type": "wait"}` при открытии «Как войти?»; сервер переводит соединение в лобби-список (как при входе в аккаунт), у которого нет 5-секундного тайм-аута. Старые серверы его просто игнорируют.
3. **Невидимость** — эффект `invisible`. `Match.hidden(p)`: мобы сбрасывают цель, зомби и лесные стражи не стреляют/не идут, стражи арены не просыпаются. Отрисовка — `draw_field(..., viewer)`: себе по сети — полупрозрачно, остальным — мерцание.
