## Why

Пользователь: «Толчки» — чаще; «скорость» убрать из общих артефактов; отдельная страница справки «Артефакты мобов» с ботинками, бронёй, автоматом и мечом.

## What Changes

- «Толчки»: три остановки по 0,5 с через 0,9 с (было через 1,5 с); весь эффект — 2,3 с.
- «Скорость» больше не выпадает из мобов и не показывается в справке (`RETIRED_ITEMS`); сам эффект и тестовая команда `/give` остались — для проверок.
- Справка: новая вкладка «Артефакты мобов» (после «Общих») — снаряжение из арены; из «Общих» снаряжение ушло. Ширина вкладок — по надписи.

## Capabilities

### Modified Capabilities
- `artifact-effects`: толчки чаще; скорость убрана.
- `menus`: вкладка «Артефакты мобов».

## Impact

- `duel/config.py`, `duel/match.py`, `duel/items.py`, `duel/client_menus.py`, `duel/screens_menus.py`, `duel/i18n.py`, `RUNBOOK.md`, тесты.
