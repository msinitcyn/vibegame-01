# Design

## Decisions

1. **Ледяная тропа** — эффект `icewalk` на `DURATION["icewalk"] = 8` с. Пока он есть, урон чужой земли не начисляется, и каждые `ICE_STEP = 14` px пройденного пути матч кладёт кусок следа `IceTrail(x, y, owner)` радиусом `ICE_R = 22` на `ICE_LIFE = 6` с. «Опасная земля» для мага: (на половине соперника и не на своём следе и без `icewalk`) или (на следе соперника). Опасная земля — тот же урон `FOE_LAND_DPS` с тем же счётчиком.
2. **Стена деревьев** — `TreeWall`: отрезок от края мага по прицелу, растёт со скоростью `TREE_SPEED` до `TREE_LENGTH = 450`, толщина `TREE_W = 26`, живёт `TREE_TIME = 8` с; последние `FADE = 0.8` с начало отрезка уходит от мага к концу. Столкновение — «капсула» (отрезок с радиусом `TREE_W / 2`). Маг после шага выталкивается из капсулы по перпендикуляру; моб пробует шаг, затем по одной оси, иначе стоит. Пуля или снаряд, оказавшиеся в капсуле, гаснут.
3. **Притяжение** — эффект `pulled` у соперника на `PULL_TIME = 3` с с указанием, кто тянет; каждый такт после движения маг сдвигается к тянущему на `PULL_SPEED · dt` (`PULL_SPEED = 220` px/с при скорости мага 300 — убежать можно, медленно), затем — обычные ограничения (поле, арена, деревья).
4. **Луч** гаснет так же, как деревья: последние `FADE` с его начало уходит к концу; касание считается по оставшемуся отрезку.
5. **Подбор**: фильтр «только свой герой» снят; выпадение по-прежнему по герою добившего (`HERO_ONLY_ITEMS`).
6. **Справка**: страница 2 — артефакты героев (значок, герой, описание), страница 3 — правила; листание по кругу.
