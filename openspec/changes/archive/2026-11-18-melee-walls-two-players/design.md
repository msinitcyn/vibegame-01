# Design

## Context

Компьютерный соперник — отдельный модуль; игра подключает его через уровень сложности, имя «Компьютер», подмену ввода красного и отдельные пункты меню. Длинные тестовые прогоны партий тоже используют его как «второго игрока». Стена отражает пули соперника, пересёкшие её лицевую сторону, и поглощает пули хозяина, пересёкшие тыльную. Мобы двигаются по прямой к цели, препятствий не учитывают. Ввод — по физическим клавишам и кнопкам геймпада, которые переводятся в действия игрока; R2 превращается в «нажатие» по порогу оси.

## Goals / Non-Goals

**Goals:**
- Удалить компьютерного соперника целиком, не оставив мёртвого кода и текстов.
- Стена — препятствие для мобов, «прозрачная» для выстрелов хозяина.
- Ближний удар — простое действие по кнопке, с тем же подходом к вводу, что и выстрел.

**Non-Goals:**
- Удар по магам и двойникам, отражение пуль ударом, комбо, анимация персонажа.
- Обход стены мобом «по навигации» — достаточно скольжения вдоль неё.
- Влияние стены на снаряды мобов (по-прежнему не действует).

## Decisions

1. **Удаляем модуль компьютера и всё, что его вызывает.** Меню строится из оставшихся пунктов, красный всегда управляется игроком. Тесты, которым нужен «живой» второй игрок для длинных прогонов, используют простого бота со случайным вводом внутри тестов — так проверяется устойчивость игры, без поддержки ИИ в коде игры. Альтернатива — оставить ИИ «на потом» — противоречит запросу и оставила бы мёртвый код.

2. **Стена против мобов — скольжение по осям.** Стена — прямоугольник; при движении моба проверяем, пересекает ли круг моба прямоугольник стены. Если шаг ведёт внутрь — пробуем сдвинуться только по вертикали, потом только по горизонтали, иначе стоим. Моб «съезжает» вдоль стены и обходит её с торца. Альтернатива — поиск пути — избыточна для одного короткого отрезка.

3. **Свои выстрелы проходят** — у стены остаётся только проверка лицевой стороны для пуль соперника; ветка поглощения своих пуль удаляется.

4. **Ближний удар — действие игрока с перезарядкой**, как выстрел: кнопка → проверка перезарядки → урон всем мобам в радиусе (край мага + 30 px до края моба). Урон 2 через общий метод «моб получил урон от игрока», чтобы злость, смерть и выпадение артефакта работали одинаково для пуль и удара. Взмах — кратковременный эффект на маге, рисуется дугой-кольцом вокруг него.

5. **Ввод удара.** Клавиатура: E и правый Shift (рядом с остальными клавишами каждого игрока). Геймпад: L1 — кнопка, L2 — ось с порогом, превращаемая в одно нажатие, ровно как R2 для выстрела.

6. **Звук удара** — третий звук выстрела, который лежал в проекте без дела.

## Risks / Trade-offs

- [Без компьютера нельзя играть одному] → осознанное решение заказчика; тестовый режим остаётся.
- [Тесты силы ИИ и уклонения исчезают] → удаляются вместе с функцией; общий прогон партий остаётся на случайном боте.
- [Мобы могут «застревать» за длинной стеной] → стена живёт 8 с, скольжение выводит моба к торцу; приемлемо.
- [Удар делает мобов слабее] → урон и дальность — в настройках; проверить в игре.
