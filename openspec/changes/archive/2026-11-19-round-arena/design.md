# Design

## Decisions

1. `ARENA = (WIDTH / 2, (TOP + BOTTOM) / 2)`, `ARENA_R = 150`; `BLUE_LAND = (0, WIDTH / 2)`, `RED_LAND = (WIDTH / 2, WIDTH)`; `MOB_ZONE` убран.
2. Маг: после шага и ограничения своей половиной — если центр ближе `ARENA_R + r` к центру арены, выталкивается по радиусу на край (в своей половине радиус не уводит на чужую).
3. «На своей земле» = в своей половине и вне арены (`in_land`). Пачки и места двойников выбираются случайно с отбрасыванием точек в арене; двойники — только в столбцах `|x − cx| > ARENA_R + r`.
4. Места мобов: равномерно в круге радиуса `ARENA_R − MOB_RADIUS − 4` (угол и `sqrt` радиуса), по возможности не на другом мобе.
5. Фон: земли героев по половинам (кромки встречаются на центральной линии), поверх — круг текстуры `bg_arena` (квадрат, рисуется генератором), маска круга, кромка: левая дуга — `HERO_EDGE` левого героя, правая — правого.
