## ADDED Requirements

### Requirement: Страница состояния сервера
С `--status-port` сервер SHALL отдавать по HTTP сводку состояния (версия, время работы, комнаты, игроки, законченные партии, ошибки за последний час и последняя ошибка, длительность тактов) и `/health`: 200, пока главный цикл работает, и 503, если он не отмечался 5 секунд. По умолчанию страница MUST быть доступна только с этого компьютера.

#### Scenario: Жив ли сервер
- **WHEN** сервер запущен с `--status-port 5557` и работает
- **THEN** `curl http://127.0.0.1:5557/health` отвечает «ok» (200), а `/` — сводкой с числом комнат и игроков
