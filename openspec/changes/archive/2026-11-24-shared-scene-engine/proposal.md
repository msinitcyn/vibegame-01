## Why

Автор попросил рефакторинг: вынести общие сервисы, чтобы переиспользовать в анимации (роликах, сценках) и в игре. Сценки «Обучения» и сцены роликов были двумя разными движками маленькой партии по сценарию (с разными форматами сценариев), «участок поля без искажений» и тряска были написаны дважды, кадр сцены рисовался в двух местах, бессмертие мобов — заплатками, сияние лечения и очищения — повтором.

## What Changes

- `duel/scene.py` — одна сцена (`Scene`, бывший `movie.Stage`) с API и сценарием `"do"`; `fit_view` (участок поля в пропорциях, без искажений); `Shake` (тряска — и в роликах, и поля в игре).
- Сценки «Обучения» (`Demo`) — та же сцена по кругу в окошке 2:1; 25 сценариев `assets/demos/*.json` переведены в формат `"do"` (поведение то же), сценкам доступен весь API (появление, артефакты на поле, ходьба к точке…).
- Ролик (`movie.py`) — только последовательность сцен, переходы, субтитры.
- `Screens.scene_frame` — один способ нарисовать кадр сцены (сценки и ролики).
- Бессмертие моба — флаг `Mob.immortal` (сцены), вместо подкручивания жизней снаружи.
- `fx.halo` — светящееся пятно (лечение, очищение).
- Правила партии не меняются (эталонный отпечаток тот же).

## Capabilities

### Modified Capabilities
- `movies`: API сцены — общий для роликов и сценок «Обучения».
