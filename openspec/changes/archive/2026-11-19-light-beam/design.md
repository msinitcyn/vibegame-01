# Design

## Decisions

1. `Beam`: начало — центр мага, направление — прицел в момент применения (маг стоит, луч не поворачивается), длина растёт со скоростью `BEAM_SPEED` до `BEAM_LENGTH`. Касание — расстояние от центра цели до отрезка не больше её радиуса + половины `BEAM_WIDTH`.
2. Урон по времени касания: новая цель — удар сразу, дальше раз в `1 / BEAM_DPS` с; вышла из луча — счёт сначала.
3. Маг стоит: эффект `beaming` на `DURATION["beaming"]`, `frozen` учитывает его; стрелять можно.
4. `HERO_ONLY_ITEMS = {"beam": "light"}`: при выпадении список видов фильтруется по герою добившего; при подборе — чужой артефакт героя пропускается.
