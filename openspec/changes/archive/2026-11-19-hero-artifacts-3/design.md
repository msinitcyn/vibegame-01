# Design

## Decisions

1. **Медведь** — эффект `bear` и `Player.bear_saved` (жизни до превращения). Урон медведю — через `hurt_player`: жизни медведя падают, на 0 превращение кончается (маг не гибнет). Конец эффекта по времени проверяется в цикле магов. Размер, скорость, запрет стрельбы — в свойствах `radius`, `speed_mult`, `can_fire`.
2. **Огненный круг** — `FireRing(x, y, owner)` с набором «кто внутри» на момент появления. После движения каждого мага — удержание по свою сторону стены; урон — только сопернику хозяина, накоплением как у чужой земли. Пули и снаряды: если за такт перешли из `d < R` в `d >= R` — гаснут.
3. **Героические артефакты** — `HERO_ONLY_ITEMS` (артефакт → герой); в общих разделах справки их нет, а страницы героев строятся по героям, не больше 6 артефактов на страницу.
