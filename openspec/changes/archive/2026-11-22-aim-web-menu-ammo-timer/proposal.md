## Why

В браузере стрельба шла только прямо или по диагонали: там по умолчанию стоял прицел «по движению». Этот режим нужен только двоим за одним компьютером, где у кого-то нет мыши или стика; везде, где играет один человек, прицел — мышью. Меню браузерной версии повторяло десктоп: «Выход» там не нужен, а «Играть по сети» — это подключение к серверу (свой сервер браузер не запускает). У пачек патронов не было видно, сколько они ещё пролежат.

## What Changes

- Прицел «по движению» работает только у двоих за одним компьютером (и только если выбран в настройках); по сети, в разминке, в тесте с ботом, в повторе и в браузере — всегда стик и мышь. Настройка называется «Прицел вдвоём».
- Браузер: нет кнопки «Выход» и подсказки про неё; «Подключиться к серверу» вместо «Играть по сети»; версия без проверки обновлений; в настройках нет прицела вдвоём, обновлений и отчётов о падениях.
- Пачка патронов: рядом таймер, как у артефакта (общий `draw_timer`).

## Capabilities

### Modified Capabilities
- `controls`: прицел по движению — только вдвоём за одним компьютером.
- `distribution`: меню браузерной версии.
- `artifacts`: таймер у пачки патронов.
