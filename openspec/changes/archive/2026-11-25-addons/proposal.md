## Why

Лабораторию баланса хочется запускать прямо из игры, но рядовому игроку она не нужна. Вместо того чтобы встраивать в игру каждый инструмент разработчика, нужна поддержка аддонов: маленький публичный API, и лаборатория — первый аддон. В перспективе аддоны смогут рисовать на поле (радиусы артефактов, оценку урона) и т. п. Десктопная версия становится инструментом владельца, публичная — браузерная; аддоны — только на десктопе.

## What Changes

- Аддоны: Python-файлы (или папки) в `~/.config/duel/addons/`, плюс встроенные в игру (выключены по умолчанию). У аддона — `register(api)`. Список и включение — «Настройки → Дополнительно → Аддоны…»; включённые запоминаются и грузятся при запуске; ошибка в аддоне не роняет игру — аддон выключается, ошибка видна в списке.
- API v0 (нестабильный): экран аддона из простых строк (выбор ◀ ▶, число, текст, кнопка, надпись, полоса прогресса, текст с прокруткой) — рисуется и управляется как настройки (клавиатура, мышь, геймпад); фоновая работа с прогрессом; рисование поверх поля по снимку (только то, что видит клиент); папка повторов и открыть «Повторы»; хранилище настроек аддона; лог.
- Встроенный аддон «Лаборатория»: форма (режим: отчёт / стратегии / перебор, партий, уровень, стратегия, герои, «--set»), «Запустить» — в фоне на всех ядрах с низким приоритетом, прогресс, «Остановить»; отчёт — на экране и в файл; повторы прогона — в «Повторах».
- Встроенный пример «Радиусы»: рисует вокруг своего мага дальность ближнего удара и огненного круга — образец рисования на поле.
- Ядро лаборатории — в `duel/lab.py` (библиотека); `tools/lab.py` — тонкая командная строка над ней.
- В браузере аддонов нет.

## Capabilities

### New Capabilities
- `addons`: аддоны и API v0.

### Modified Capabilities
- `balance-lab`: запуск из игры.

## Impact

Новое: `duel/addons.py` (загрузка, API, экраны), `duel/addons_builtin/lab.py`, `duel/addons_builtin/ranges.py`, `duel/lab.py`, тесты. Изменено: `tools/lab.py` (обёртка), `duel/game.py`, `duel/client_menus.py`, `duel/client_input.py`, `duel/screens.py` (слой поля), `duel/screens_menus.py`, `duel/i18n.py`, `main.py` (`freeze_support` — процессы в собранной игре), RUNBOOK. Протокол и сервер — без изменений.
