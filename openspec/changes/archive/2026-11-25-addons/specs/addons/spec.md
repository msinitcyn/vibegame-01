## ADDED Requirements

### Requirement: Аддоны
Настольная игра SHALL загружать аддоны — Python-модули с функцией `register(api)` — из встроенных и из папки `addons` рядом с настройками; список, включение и выключение — в «Настройки → Дополнительно → Аддоны»; включённые MUST запоминаться между запусками. Ошибка в аддоне MUST NOT ронять игру: аддон выключается, ошибка видна в списке. Браузерная версия аддонов MUST NOT иметь.

#### Scenario: Сломанный аддон
- **WHEN** аддон бросает исключение при загрузке или в своём экране
- **THEN** игра работает дальше, аддон выключен, в списке видна ошибка

### Requirement: API аддонов v0
API SHALL давать аддону: свой экран из простых строк (выбор, число, текст, кнопка, надпись, прогресс, текст с прокруткой), управляемый как настройки; фоновую работу с прогрессом и остановкой; рисование поверх поля по снимку, видному клиенту; папку повторов и открытие «Повторов»; хранилище настроек аддона. API MUST NOT давать менять партию.

#### Scenario: Радиусы
- **WHEN** включён встроенный аддон «Радиусы», и идёт партия
- **THEN** вокруг своего мага нарисованы дальность ближнего удара и огненного круга
