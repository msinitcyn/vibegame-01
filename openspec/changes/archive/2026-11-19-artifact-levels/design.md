# Design

## Decisions

1. Уровень — таблица `ITEM_LEVEL` в настройках (артефакт → 1..4), чтобы дети могли перекидывать.
2. Выпадение: кандидаты — артефакты, которые может получить добивший (свои героические и общие), с уровнем, разрешённым жизнями моба (`LEVEL_MIN_MOB_HP` по полному запасу жизней моба); выбор — `rng.choices` с весами `LEVEL_WEIGHT[уровень]`.
3. Точки уровня рисует `draw_icon` (снизу по кольцу значка); в строке статуса эффектов — без точек.
