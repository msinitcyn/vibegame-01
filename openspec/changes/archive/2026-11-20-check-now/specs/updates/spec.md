## ADDED Requirements

### Requirement: Проверить обновления сейчас
В настройках SHALL быть строка «Проверить обновления», которая сразу спрашивает GitHub о новой версии (даже если автоматическая проверка выключена) и показывает итог: идёт проверка, есть версия X, у вас последняя версия или нет связи — вместе со временем последней проверки. В главном меню рядом с номером версии MUST быть время последней проверки; щелчок по нему MUST проверять заново. Время и итог последней проверки MUST сохраняться между запусками.

#### Scenario: Выпуск собрался, пока игра была открыта
- **WHEN** игра запущена до появления 0.6.0 на GitHub, а потом игрок нажал «Проверить обновления»
- **THEN** в меню появляется «Обновить до 0.6.0»

#### Scenario: Нет интернета
- **WHEN** игрок нажал «Проверить обновления» без интернета
- **THEN** рядом написано «нет связи с GitHub» и время проверки
