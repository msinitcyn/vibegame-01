# Design

## Протокол 7 (в лобби сервера)

```
клиент -> {"type": "lobby", "name": "Маша"}         войти в лобби: список приходит сразу и раз в 0,5 с
сервер -> {"type": "lobby", "server": "Дом", "you": 4,
          "players": [{"id", "name", "status": "lobby"|"seeking"|"picking"|"playing"|"watching", "account": bool}],
          "games": [{"room", "phase", "time", "spectators", "blue": {"name", "hero"}, "red": {...}}]}
клиент -> {"type": "challenge", "to": 7}            вызов          {"type": "cancel"} — отменить свой вызов
сервер -> {"type": "challenged", "from": 4, "name": "Маша", "left": 20}   — тому, кого вызвали
клиент -> {"type": "answer", "from": 4, "accept": true|false}
сервер -> {"type": "declined", "name", "why": "no"|"timeout"|"busy"|"cancel"}   — вызвавшему (или вызванному при cancel)
клиент -> {"type": "seek"} / {"type": "unseek"}     ищу соперника
клиент -> {"type": "bot_game"}                      партия с ботом
сервер -> {"type": "seat", "room", "you", "token"}  — обоим, когда партия создана (дальше — state, как раньше)
сервер -> {"type": "room_closed", "why": "left"|"lost"}   — соперник ушёл: снова в лобби
```
`rooms` / `create` / `join` остаются (тесты, `--connect`, зрители: `join` с `role: spectator`).

## Решения

1. **Участник лобби** — `Member(id, name, conn)`; статус считается: в комнате — по фазе комнаты и роли (picking / playing / watching), иначе — seeking или lobby. Список рассылается тем, кто в лобби, раз в 0,5 с и сразу при вызове/ответе.
2. **Вызов** — один исходящий у игрока и один входящий у вызванного; занятому (в партии, уже вызван) — `declined: busy`. 20 с без ответа — `timeout`. Принятие, подбор и `bot_game` создают комнату и сажают игроков (вызвавший — синий); комната — в фазе выбора героя (`lobby`).
3. **Реванш** — `over` + все готовы → снова фаза выбора героя (а не сразу бой).
4. **Закрытие партии** — если человек ушёл из комнаты сам (`leave`) или не вернулся за 30 с, остальные (игрок и зрители) получают `room_closed` и возвращаются в лобби; комната удаляется.
5. **Клиент** — состояние `lobby` (вместо `rooms`); окна поверх лобби: входящий вызов (принять / отказаться, таймер), исходящий (ждём… / отменить), отказ. Разминка — из лобби, соединение держится; вызов или найденный соперник её прерывают. Выбор героя по сети — экран как за одним компьютером (свой ряд — управляешь, ряд соперника — смотришь), поверх — отсчёт сервера. После партии — кнопки «Реванш» и «В лобби».
