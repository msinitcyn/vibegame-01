# Proposal

## Why

В меню можно было ходить только клавиатурой и геймпадом; мышь не работала, наведение ничего не подсвечивало.

## What Changes

- Во всех меню (главное, настройки, справка, выбор героев, серверы, комнаты, вход, обновление, лобби комнаты, экран победы) наведение мыши выбирает пункт (подсветка, как стрелками), левая кнопка — нажимает.
- Строки настроек со стрелками ◀ ▶: щелчок по левой половине — назад, по правой — вперёд. Справка: левая/правая половина экрана — листать.
- Правая кнопка — «назад» (как Esc), кроме главного меню (там Esc — выход из игры) и лобби комнаты (там уход — кнопкой).
- Новые кнопки: «←» на экранах, «Выход» в главном меню; в лобби комнаты — «Готов», «Бот», «Разминка», «Выйти»; щелчок по своей карточке — сменить героя; кнопки на экране обновления; щелчок по экрану победы — «ещё раз».
