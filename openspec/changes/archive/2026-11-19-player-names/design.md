# Design

## Context

Настройки — `duel/settings.py` (язык, последний адрес), экран — строки `["lang", "back"]`, клавиши `settings_key`. Имена в панели и на экране победы — `tr("name." + pid)`. Сервер (`duel/server.py`) знает только соединения по цвету; ответ на поиск содержит имя компьютера. Протокол 2 уже выпущен (v0.2.1).

## Goals / Non-Goals

**Goals:** имя в настройках, имена в сетевой партии и в поиске, бот подписан; автовыбор найденной игры.

**Non-Goals:** имена в хотсите (два игрока за одним компьютером — у компьютера одно имя в настройках), лобби, переподключение, уникальность имён.

## Decisions

1. **Ввод имени по событию текста pygame (`TEXTINPUT`)**, а не по физическим клавишам: имя может быть по-русски или по-фински. Пока выбрана строка «Имя», клавиши-буквы не управляют экраном (листание — стрелками, Esc — назад, Enter — следующая строка). Длина — до 16 символов, только печатные символы; лишние пробелы по краям обрезаются при сохранении.

2. **Протокол без смены версии.** После приветствия клиент шлёт `{"type": "name", "name": "Маша"}`. Сервер хранит имена мест (обрезает до 16 символов, убирает непечатные), а в каждом снимке-сообщении шлёт `"names": {"blue": "Папа", "red": "Маша"}` и `"bots": ["red"]` (места, где сейчас играет бот). Старые клиенты эти поля не читают, старые серверы не шлют — у клиента остаются цвета.

3. **Подпись игрока в панели и на экране победы** — функция приложения `player_label(pid)`: имя из последнего сообщения сервера → «Бот», если место у бота → цвет. В хотсите имён нет — цвета.

4. **Имя в ответе на поиск** — имя синего игрока (создатель игры из меню подключается первым и становится синим), если оно задано, иначе имя компьютера.

5. **Автовыбор**: флаг «игрок трогал выбор» (`join_touched`) сбрасывается при открытии экрана и ставится при наборе, Backspace и стрелках. Пока он не стоит и выбрана строка ручного ввода, а список не пуст — выбирается первая игра.

## Risks / Trade-offs

- [Два игрока с одинаковым именем] → видно по цвету; уникальность не нужна.
- [В имени — символы, которых нет в шрифте] → покажутся пустыми квадратами; не критично.
