# Design

## Decisions

1. Внутреннее имя `evil` → `dark` (сетевая версия 3 с героями ещё не выпущена — совместимость не нужна).
2. Свет: цвет `(255, 214, 80)`, раскраска мантии `#e8c440`/`#a07c1c`/`#fff4b0`, звезда `#ffffff`; фон `bg_light` — тёмный тёплый камень (пули на нём читаются), кромка `#d2a02a`.
3. Порядок листания: Огонь, Холод, Природа, Тьма, Свет.
4. Ширина карточки выбора — по числу героев.
