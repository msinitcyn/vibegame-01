# Proposal

## Why

Каждую новую версию сейчас надо скачивать со страницы выпусков и ставить руками на каждом компьютере. Хочется как в больших играх: «Доступна новая версия — Обновить».

## What Changes

- При запуске игра в фоне спрашивает GitHub Releases о последней версии (без задержки меню; нет сети — молча работает дальше).
- Новее своей — в меню пункт «Обновить до X». Он скачивает файл своей системы, проверяет его по `SHA256SUMS` выпуска и ставит:
  - Linux: заменяет свой файл игры (`~/.local/bin/spellgunners`) и перезапускается;
  - Windows: тихо запускает установщик выпуска и закрывается; установщик ставит новую версию и запускает её.
- Экран обновления: «Скачиваю… N %», «Проверяю», ошибка с причиной; Esc — назад, пока не начата установка.
- Запуск из исходников: только надпись «Есть версия X — обновить: git pull».
- Сетевая ошибка «другая версия игры» подсказывает про обновление, если оно есть.
- Настройка «Проверять обновления» (да/нет), по умолчанию — да.
- Сборка: версия вшивается в игру (`duel/_version.py`); выпуск получает `SHA256SUMS`; установщик Windows после тихой установки запускает игру.

## Capabilities

### New Capabilities

- `updates`: проверка, скачивание, проверка суммы, установка новой версии.
