## ADDED Requirements

### Requirement: Проверка новой версии
При запуске игра SHALL в фоне узнавать на странице выпусков GitHub номер последней версии, не задерживая меню. Если сети нет или ответ не пришёл, игра MUST работать дальше без сообщений. Проверку MUST можно выключить в настройках («Проверять обновления»).

#### Scenario: Есть новая версия
- **WHEN** у игрока версия 0.4.0, а последний выпуск — 0.5.0
- **THEN** в меню появляется пункт «Обновить до 0.5.0»

#### Scenario: Нет сети
- **WHEN** компьютер не подключён к интернету
- **THEN** меню работает как обычно, без пункта обновления и без ошибок

### Requirement: Обновление одной кнопкой
Пункт «Обновить» SHALL скачивать файл выпуска для своей системы, показывая долю скачанного, проверять его по контрольной сумме из выпуска и только при совпадении ставить. На Linux игра MUST заменить свой файл и перезапуститься; на Windows — запустить установщик выпуска без вопросов и закрыться, а установщик — запустить новую версию. При любой ошибке MUST показываться причина, а старая версия — оставаться рабочей.

#### Scenario: Битый файл
- **WHEN** скачанный файл не совпадает с контрольной суммой
- **THEN** игра пишет «файл повреждён» и ничего не ставит

#### Scenario: Успешное обновление на Linux
- **WHEN** игрок нажал «Обновить», файл скачан и проверен
- **THEN** файл игры заменён новым, и игра перезапускается уже новой версией

### Requirement: Запуск из исходников
Игра, запущенная из исходников, SHALL только сообщать о новой версии (с подсказкой `git pull`) и MUST NOT заменять файлы.

#### Scenario: Разработчик
- **WHEN** игра запущена командой `python main.py`, а на GitHub есть версия новее
- **THEN** в меню надпись о новой версии, пункта «Обновить» нет

### Requirement: Подсказка при другой версии в сети
Если подключение не удалось из-за другой версии игры, а обновление доступно, сообщение SHALL предлагать обновиться через меню.

#### Scenario: Друг обновился раньше
- **WHEN** у друга 0.5.0, у меня 0.4.0, и я подключаюсь к его игре
- **THEN** ошибка подключения подсказывает «в меню есть „Обновить“»
