## ADDED Requirements

### Requirement: Сборки без предустановки
Для Linux и Windows SHALL быть готовые сборки игры, внутри которых всё нужное для запуска: Python, библиотеки, картинки, звуки, музыка и шрифты. Запуск сборки MUST NOT требовать установленного Python, pygame или других пакетов.

#### Scenario: Чистый Windows
- **WHEN** на компьютере с Windows без Python запускают `duel-windows.exe`
- **THEN** открывается игра со звуком, музыкой и картинками

#### Scenario: Linux без окружения
- **WHEN** на Ubuntu без окружения Python игры запускают `duel-linux`
- **THEN** открывается игра

### Requirement: Установщик Windows
Для Windows SHALL быть установщик `duel-setup.exe`, который без прав администратора ставит игру в папку пользователя, создаёт ярлыки в меню «Пуск» и (по выбору) на рабочем столе и регистрирует удаление в списке программ.

#### Scenario: Установка и ярлык
- **WHEN** ребёнок запускает `duel-setup.exe` и проходит шаги установки
- **THEN** в меню «Пуск» появляется «Дуэль шариков» со значком, и игра запускается с ярлыка

### Requirement: Установка на Linux
Рядом с Linux-сборкой SHALL лежать скрипт установки, который кладёт игру в `~/.local/bin` и добавляет её в меню приложений со значком, без прав администратора.

#### Scenario: Меню приложений
- **WHEN** пользователь запускает `install.sh`
- **THEN** «Дуэль шариков» появляется в меню приложений и запускается оттуда

### Requirement: Шрифты и значки в любой системе
Игра SHALL брать шрифты из своих файлов, а не из системы, так что русские и финские буквы и значки интерфейса (♥, ✕, △, ○, ◀, ▶) MUST отображаться одинаково на Linux и Windows. У окна и ярлыков MUST быть значок игры.

#### Scenario: Windows без DejaVu
- **WHEN** игру запускают на Windows, где нет шрифта DejaVu Sans
- **THEN** меню и статус показывают кириллицу и значки кнопок геймпада правильно

### Requirement: Настройки в папке пользователя
Настройки SHALL храниться в папке пользователя, принятой в системе: на Windows — `%APPDATA%\duel`, на Linux — `~/.config/duel`. Переустановка или обновление игры MUST NOT сбрасывать настройки.

#### Scenario: Обновление
- **WHEN** на Windows ставят новую версию игры поверх старой
- **THEN** выбранный язык и последний адрес сервера сохраняются

### Requirement: Выпуск версии
Публикация версии (метка `v*` в репозитории на GitHub) SHALL автоматически собирать Linux-сборку, Windows-сборку и установщик и прикладывать их к странице выпуска.

#### Scenario: Новая версия
- **WHEN** в репозиторий на GitHub отправлена метка `v0.2.0`
- **THEN** на странице выпуска `v0.2.0` появляются `duel-linux`, `install.sh`, `duel-windows.exe` и `duel-setup.exe`
