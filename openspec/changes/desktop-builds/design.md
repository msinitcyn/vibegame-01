# Design

## Context

Игра — Python 3.12 + pygame 2.6 (колёса pygame уже содержат SDL, звук mp3 и шрифтовый движок). Файлы игры ищутся от `duel/config.py`: `ASSETS = Path(__file__).parent.parent / "assets"`. Шрифты — `pygame.font.SysFont("dejavusans")`: на Ubuntu есть, на Windows нет (подставится шрифт по умолчанию без гарантии кириллицы и значков ♥ ✕ △ ○). Настройки — `~/.config/duel/settings.json` (на Windows тоже уйдут в `~/.config`, что непривычно). Целевые системы — Ubuntu и Windows. Репозиторий будет на GitHub.

## Goals / Non-Goals

**Goals:**
- Один файл на систему со всем внутри; установщик с ярлыками на Windows; установка в меню на Linux.
- Одинаковые шрифты и значки везде.
- Выпуск версии без ручной сборки на Windows.

**Non-Goals:**
- macOS.
- Подпись сборок сертификатом (Windows SmartScreen при первом запуске предупредит — «Подробнее» → «Выполнить в любом случае»).
- Автообновление, магазины приложений, Flatpak/Snap/.deb.

## Decisions

1. **PyInstaller, режим «один файл».** Самый распространённый упаковщик для pygame; один файл проще отдать ребёнку. При запуске он распаковывается во временную папку (около секунды) — приемлемо. Альтернативы: Nuitka (быстрее, но сборка долгая и капризная), режим «одна папка» (быстрее старт, но много файлов — для установщика Windows можно и так, но единообразие важнее).

2. **Корень файлов игры — `sys._MEIPASS` в сборке**, иначе — папка проекта. Одна функция в `config.py`; `assets/` кладётся в сборку целиком (`--add-data`).

3. **Шрифт DejaVu Sans (обычный и жирный) — в `assets/fonts/`**, загрузка `pygame.font.Font(путь, размер)`. Лицензия DejaVu разрешает распространение (файл лицензии кладётся рядом). Проверено, что DejaVu содержит кириллицу, финские буквы и все используемые значки.

4. **Настройки на Windows — `%APPDATA%\duel\settings.json`**; на Linux без изменений (`XDG_CONFIG_HOME` или `~/.config`). Переменная `DUEL_SETTINGS` по-прежнему главнее (тесты).

5. **Значок**: `assets/icon.png` (64×64, маг из спрайта, рисуется `tools/build.py` при сборке, если файла нет; хранится в репозитории) — для окна (`pygame.display.set_icon`) и Linux-меню; `.ico` для Windows делается из него Pillow при сборке.

6. **Установщик Windows — Inno Setup** (`packaging/windows/duel.iss`): установка «для текущего пользователя» в `%LOCALAPPDATA%\Programs\Duel` (без администратора), ярлык в «Пуск», флажок «ярлык на рабочем столе», удаление. Inno Setup бесплатный и ставится на машину сборки GitHub одной командой.

7. **Linux-установка — `packaging/linux/install.sh`**: копирует `duel-linux` в `~/.local/bin/duel`, значок — в `~/.local/share/icons`, создаёт `~/.local/share/applications/duel.desktop`. Без администратора. Сборка Linux делается на Ubuntu 22.04 (GitHub), чтобы работала и на более старых системах (сборка зависит от версии системной библиотеки C).

8. **GitHub Actions** (`.github/workflows/release.yml`): по метке `v*` две задачи — `ubuntu-22.04` и `windows-latest`: поставить Python 3.12, pygame, PyInstaller, Pillow (Windows — ещё Inno Setup), прогнать `pytest`, собрать `tools/build.py`, приложить файлы к выпуску. Можно запустить и вручную (`workflow_dispatch`) — тогда файлы лежат в результатах задачи.

9. **`tools/build.py`** — одна команда для обеих систем: значок, PyInstaller с нужными параметрами, на Windows — ещё Inno Setup, если он найден. Локально на Linux: `.venv/bin/python tools/build.py` → `dist/duel-linux`.

## Risks / Trade-offs

- [Windows-сборку нельзя проверить на этом ноутбуке] → её собирает и прогоняет тесты GitHub; первый запуск проверяется на компьютере ребёнка; ошибки чинятся следующей версией.
- [Антивирусы иногда ругаются на однофайловые сборки PyInstaller] → установщик и подпись помогли бы; пока — исключение в антивирусе, если понадобится.
- [Размер файла ~30–50 МБ из-за Python, SDL и музыки] → приемлемо.
- [Распаковка при каждом запуске] → секунда задержки; если станет мешать — режим «одна папка» для установщика.
