# Proposal

## Why

Сейчас игра ставится вручную: скопировать папку, создать окружение Python, поставить pygame. На компьютеры детей (Linux и Windows) нужна «толстая» сборка — скачал и играешь, без Python и пакетов. Код будет лежать на GitHub, оттуда же удобно брать готовые сборки.

## What Changes

- **Сборка в один файл со всем внутри** (Python, pygame с SDL, картинки, звуки, музыка, шрифты): для Linux — исполняемый файл `duel-linux`, для Windows — `duel-windows.exe`. Ничего ставить заранее не нужно.
- **Установщик для Windows** (`duel-setup.exe`): ставит игру в папку пользователя, создаёт ярлыки в меню «Пуск» и на рабочем столе, есть удаление через «Программы и компоненты». Права администратора не нужны.
- **Установка на Linux**: скрипт `install.sh` рядом со сборкой кладёт игру в `~/.local/bin` и добавляет её в меню приложений со значком.
- **Шрифты внутри игры**: сейчас игра берёт DejaVu Sans из системы, а на Windows его нет — русские буквы и значки (♥, ✕, △, ○) могли бы пропасть. Шрифт кладётся в `assets/fonts` и загружается из файла.
- **Пути к файлам игры** работают и из папки с кодом, и изнутри сборки.
- **Настройки на Windows** — в `%APPDATA%\duel` (на Linux по-прежнему `~/.config/duel`).
- **Значок игры** (маг) для окна, ярлыков и меню.
- **Сборка на GitHub**: при публикации версии (метка `v*`) GitHub сам собирает Linux и Windows и прикладывает файлы к странице выпуска. Локально Linux-сборка делается одной командой.
- Игра для игрока не меняется.

## Capabilities

### New Capabilities

- `distribution`: готовые сборки для Linux и Windows без предустановки, установщик Windows с ярлыками, установка на Linux в меню приложений, шрифты и файлы внутри сборки, сборки на GitHub по метке версии.

### Modified Capabilities

## Impact

- Код: `duel/config.py` (корень файлов игры внутри сборки), `duel/game.py` (шрифты из файлов, значок окна), `duel/settings.py` (папка настроек на Windows), `main.py`.
- Новые файлы: `assets/fonts/` (DejaVu Sans, свободная лицензия), `assets/icon.png`, `tools/build.py` (сборка через PyInstaller), `packaging/windows/duel.iss` (Inno Setup), `packaging/linux/install.sh`, `.github/workflows/release.yml`.
- Зависимости только для сборки: PyInstaller, Pillow (значок `.ico`); игре они не нужны.
- Тесты: шрифты из файлов (кириллица и значки), пути к файлам в режиме сборки, папка настроек на Windows; Linux-сборка собирается и запускается.
- Документация: `RUNBOOK.md` (как собрать, выпустить версию, установить детям).
- Ограничение: Windows-сборку локально (на Linux) собрать нельзя — её собирает GitHub; проверить её можно только после первой публикации.
