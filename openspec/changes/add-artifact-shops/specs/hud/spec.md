# Spec Delta

## ADDED Requirements

### Requirement: Запас денег игрока
Во время партии интерфейс SHALL показывать каждому игроку его текущий запас денег так, чтобы его можно было соотнести с ценами в его магазине.

#### Scenario: После подбора денег
- **WHEN** игрок подбирает денежную награду
- **THEN** отображаемый запас его денег увеличивается на размер награды
