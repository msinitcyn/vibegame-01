# movies Specification

## Purpose
Ролики из сцен игры: движок, который гоняет по экрану запрограммированные сцены, сам добавляет переходы между ними и показывает субтитры на языке игры, — для промо-ролика, обучения и представления героев.

## Requirements

### Requirement: Ролик из сцен
Ролик SHALL быть последовательностью сцен из `assets/movies/<ролик>/movie.json`; сцена — настоящая партия по сценарию (маги, мобы, артефакты, заклинания), в которой никто не погибает, если сценарий не разрешил мобам гибнуть. Между сценами движок MUST сам добавлять переход: затемнение через чёрный, растворение, белую вспышку, шторку или склейку; ролик MUST начинаться из чёрного и кончаться в чёрный.

#### Scenario: Две сцены
- **WHEN** в ролике две сцены и переход «вспышка»
- **THEN** после первой сцены экран вспыхивает белым и показывается вторая

### Requirement: Внутренний API сцены
Сцену SHALL можно программировать вызовами API (`Scene`, `duel/scene.py`): идти, идти к точке, целиться, стрелять, бить, колдовать, переставить, появиться, исчезнуть, сменить героя, поставить моба, бросить артефакт, дать снаряжение, камера, следить за магом, тряска, замедление. Сценарий JSON MUST вызывать те же методы по времени. Сценки «Обучения» MUST быть той же сценой (тот же формат сценария), только по кругу.

#### Scenario: Смена героя
- **WHEN** сценарий в 1,0 с вызывает `hero` для синего с героем «Земля»
- **THEN** синий маг проявляется заново уже Землёй

#### Scenario: Сценка тем же API
- **WHEN** в сценарии сценки «Обучения» стоит `{"t": 0.9, "do": "cast", "who": "blue", "item": "lasso"}`
- **THEN** в окошке справки синий набрасывает лассо, как в ролике

### Requirement: Камера и кадр
Кадр ролика SHALL быть в пропорциях 16:9 с чёрными полосами сверху и снизу; камера MUST показывать заданный участок поля без искажений и MAY плавно переезжать к новому участку или следить за магом; тряска MUST сдвигать кадр.

#### Scenario: Наезд
- **WHEN** камера за 1 с переезжает со всего поля на участок вокруг мага
- **THEN** кадр плавно приближается, круги остаются кругами

### Requirement: Субтитры ролика
Надписи ролика SHALL браться из файлов субтитров `subs.<язык>.srt` (время — от начала ролика) и показываться внизу белым текстом на чёрной плашке; нет файла для языка игры — MUST браться английский. Новый язык MUST добавляться только новым файлом субтитров.

#### Scenario: Финский
- **WHEN** язык игры финский и есть `subs.fi.srt`
- **THEN** в нужные секунды внизу видны финские строки

### Requirement: Просмотр ролика
Ролик SHALL играть свою музыку (если задана) и звуки сцен; Esc MUST прерывать его. `main.py --movie <ролик>` MUST запускать ролик, F5 — перечитывать его файлы.

#### Scenario: Пропуск
- **WHEN** во время ролика игрок нажимает Esc
- **THEN** ролик кончается, игра — в главном меню

### Requirement: Ролик при старте
При обычном запуске игры SHALL сначала идти ролик `intro`, потом — меню, пока на вкладке «Обучение» → «Об игре» стоит галка «Показывать при старте» (по умолчанию стоит). Сняв галку, игрок MUST при следующих запусках сразу попадать в меню; выбор MUST сохраняться. Пересмотреть ролик MUST можно кнопкой «Смотреть ролик» на той же вкладке.

#### Scenario: Галка стоит
- **WHEN** игрок запускает игру, не трогав галку
- **THEN** идёт ролик, а после него (или после Esc) — главное меню

#### Scenario: Галку сняли
- **WHEN** игрок снял галку «Показывать при старте» и запускает игру снова
- **THEN** сразу главное меню

### Requirement: Музыка ролика при старте
Под ролик при старте (`intro`) SHALL играть фоновая музыка игры (`assets/music/background-*.mp3`) в случайном порядке: трек играет один раз, потом начинается другой, не тот же самый. Музыка меню MUST оставаться своей (`menu-*.mp3`).

#### Scenario: Запуск
- **WHEN** игра запускается с роликом
- **THEN** под ролик играет случайный фоновый трек, а после ролика в меню — музыка меню

### Requirement: Смертные маги в сцене и сцена «Побеждай»
Сцена с `"mortal_players": true` SHALL позволять магу погибнуть (с анимацией гибели); ролик `intro` MUST кончаться сценой «Побеждай!». Действия в сценах ролика MUST идти до смены кадра — кадр меняется посреди действия.

#### Scenario: Конец ролика
- **WHEN** идёт последняя сцена ролика
- **THEN** Огонь добивает Холода, из Холода вылетает дух, внизу — «Побеждай!»

### Requirement: Ролик при старте в браузере
Браузерная версия SHALL запускаться так же, как игра на компьютере: выбор языка (если не выбран), ролик (если стоит галка «Показывать при старте»), меню.

#### Scenario: Первый заход в браузере
- **WHEN** человек впервые открывает игру в браузере
- **THEN** он выбирает язык, смотрит ролик и попадает в меню
